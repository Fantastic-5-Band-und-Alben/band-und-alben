## Kanban-Phasen

| Phase | Bedeutung |
|-------|-----------|
| Backlog | erfasst, noch nicht für die Umsetzung bereit |
| To Do | bereit, kann gestartet werden |
| In Progress | jemand arbeitet daran (Branch existiert) |
| Review | Pull Request offen, wartet auf Review |
| Done | gemergt und erledigt |

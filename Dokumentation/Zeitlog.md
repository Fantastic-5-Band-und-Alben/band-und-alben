# D4 – Zeitlog

Ein Dokument für alle. Pro Modultag sieht man auf einen Blick, wer wie lange woran gearbeitet hat.

**So tragen wir ein**
- Pro Modultag gibt es einen Abschnitt. Wer am Tag zuerst einträgt, legt ihn an (neuster Tag oben).
- Pro Person und Task eine Zeile, auf **15 Minuten genau**. Mehrere Tasks am selben Tag ergeben mehrere Zeilen.
- Task = Issue-Nummer auf dem [Kanban Board](https://github.com/orgs/Fantastic-5-Band-und-Alben/projects/1). Ohne Issue: `Planung`, `Meeting`, `Fachgespräch`.
- Pro Modultag kommen etwa **160–180 Minuten** pro Person zusammen.
- Danach das Total in der Übersicht nachführen.

# D4 – Zeitlogging

- Jede Person führt eine eigene Datei `Vorname.md` (Kopie der [Vorlage](Vorlage.md)). So gibt es keine Merge-Konflikte.
- Zeit **pro Task** loggen, auf **15 Minuten genau**, nicht zusammengefasst.
- Pro Modultag kommen etwa **160–180 Minuten** zusammen.
- TaskNr = Issue-Nummer auf dem [Kanban Board](https://github.com/orgs/Fantastic-5-Band-und-Alben/projects/1). Feste Tasks ohne Issue: `Planung`, `Austausch`, `Fachgespräch`.
- Dauert ein Task viel länger als geschätzt, in der Beschreibung kurz erklären warum.

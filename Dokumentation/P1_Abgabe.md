Testen tun alle. Wir treffen uns jeden Freitag zum Sprint-Meeting. Mehr dazu unter [Meetings und Arbeitsprozesse](Meetings_Arbeitsprozesse.md).

## So arbeiten wir

- Niemand arbeitet direkt auf `main`. Alles läuft über Branch, Pull Request und Review.
- Bei jedem Pull Request prüft ein automatischer Check, ob Zeitlog, [Projektlog](../CLAUDE.md) und [Prompt-Log](../prompt-log.md) nachgeführt sind.
- Das grosse Ziel steht im [Epic #24](https://github.com/Fantastic-5-Band-und-Alben/band-und-alben/issues/24). Die User Stories folgen.

## Technologie

Wir bauen zwei Services: einen für Bands und einen für Alben. Sie reden nur über die API miteinander.

- **Band-Service:** C#. Framework, Datenbank und Begründung folgen.
- **Album-Service:** Das klärt das Team gerade ab.

Alles dazu kommt in [Applikation / Technologie](Applikation_Technologie.md).
